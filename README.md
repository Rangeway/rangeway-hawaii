# Rangeway Hawaiʻi Island

The public marketing site for Rangeway's long-term Hawaiʻi Island vision.

Production: [hawaii.rangeway.co](https://hawaii.rangeway.co/)

## Local development

The site is plain HTML, CSS, and JavaScript with no build step.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Validation

```bash
npm test
npm run check
```

See `SOURCE_ASSETS.md` for the approved concept-art provenance and `DEPLOY.md` for production operations.
